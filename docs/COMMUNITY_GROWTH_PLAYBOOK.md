I built Project J.A.R.V.I.S., an open-source Cyber-Physical AgentOS written in Python that unites the Physical World (ESP32 relays, ambient sensors), Computer World (Windows OS, Win32 windowing, Chromium CDP), and Digital World (AWS Cloud, Terraform) under a formal execution pipeline.

Why build this?
Almost all current AI agents suffer from a fundamental failure mode: they blindly trust tool execution codes or hallucinate that an action occurred when the underlying OS or hardware state never transitioned.

In J.A.R.V.I.S., we enforce a strict 0% false-success invariant:
1. Tools can never self-certify success. They only return raw execution facts.
2. Dual-Channel Corroboration: Channel 1 verifies logical state transitions, while Channel 2 independently validates physical/sensory reality (e.g. OS process tables, audio mixers, ambient lux sensors, or AWS APIs).
3. If physical reality doesn't match the expectation, the execution unconditionally fails closed and triggers automated rollback.

Key engineering details:

- Sensory Layer: Local CPU openWakeWord ONNX neural model (<15ms) with sub-10ms vocal barge-in interruption and acoustic double-clap detection.
- Cryptographic Proof of Execution: Every executed mutation generates an HMAC-signed receipt capturing pre/post state hashes and deltas.
- Tested: 285 automated pytest tests passing (100% CI green), 0 Bandit AST vulnerabilities, and an empirical 100-task SLA benchmark runner.
