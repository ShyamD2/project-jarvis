### 3. Detailed Architecture & Technical Components

#### 3.1 Web Touchpad Security Gate (services/gateway/remote_trackpad_server.py)
- **Interactive PIN Modal Gate:** When visited without an active session token, the page renders a full-screen Cyber PIN Access Gate with a numeric keypad (0–9, CLR, UNLOCK).
- **Backend Authentication Endpoint (POST /api/auth/verify_pin):** Verifies the submitted PIN against persistent storage. Returns an operator token on success or HTTP 403 / failure on error.
- **Strict Endpoint Protection:** Unauthenticated requests to /stream, /api/screen/snapshot, /ws/trackpad, and /api/mouse/* return 403 Forbidden.
- **High-Contrast Mouse Cursor:** _draw_cursor_on_image() queries active Windows cursor state via Win32 GetCursorInfo / GetCursorPos and renders a 28px neon cyan pointer with 3px black outline and red precision dot at exact coordinates.

#### 3.2 Unified Telegram Commands (services/gateway/telegram_bot.py)
- **Native Lock (Win+L):** /lock and 🔒 Lock PC trigger native power_agent.lock_workstation(), locking into Windows Winlogon.
- **PIN Change Verification (/setpin):**
  - Requires syntax: /setpin <current_pin> <new_pin>
  - Strictly compares <current_pin> with active PIN before allowing changes.
  - Automatically deletes user's command message from Telegram chat for privacy.
- **Single Master PIN:** One PIN protects both Web Touchpad and Cyber Lock simultaneously.
